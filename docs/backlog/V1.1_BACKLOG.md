# v1.1 Backlog — Deferred from MVP

These findings come from the best-practices research (`docs/research/PARTNERSHIP_BEST_PRACTICES.md`).
They are real gaps but are **Medium-cost** additions that would push past the MVP checkpoint
discipline. They are deliberately deferred. The MVP (v1.0) ships with the bounded set documented
in `docs/VALUATION_RECONCILIATION.md` (G-1, G-2, G-3, G-4, G-11, G-15).

Status: **BACKLOG — not in scope for the MVP build.**

> Note: round 1 shipped a multi-opportunity portfolio shell — six cases, with Atlas modeled
> end-to-end and five portfolio-level entries. The backlog's framing of a "single-case demo"
> (see G-12) slightly predates that; all G-5..G-16 items remain deferred.

---

| # | Gap | What it is | Why deferred | MVP sketch (for later) |
|---|-----|-----------|--------------|------------------------|
| G-5 | Exclusivity as a priced option | `exclusivity` is one enum + one lumped `exclusivityOpportunityCostUsd`. Missing option value of foreclosed alternatives, MFN / meet-or-release / carve-outs / segment-and-milestone exclusivity. | Requires an option-pricing or scenario-matrix model + sensitivities; would change the scenario engine and the seeded reconciliation. | Expand enum into a struct (segments, duration, carve-outs, MFN); drive EOC from it; add an exclusivity sensitivity to the top-5. |
| G-6 | Post-signing alliance scorecard & governance cadence | Lifecycle currently ends at realized-value tracking. Missing KPI registry, joint governance committee, escalation path, quarterly business review cadence, exit triggers. | Adds a new entity + new screens/tabs + new workflow stages; largest scope of the deferred set. | `Scorecard` entity (KPIs, targets, review dates, owners); `active` stage tooling; wire to realized-value tracking. |
| G-7 | Equity / co-investment / compute-credits structure type | The five archetypes are all contractual. Dominant frontier-AI structures blend equity, compute credits, board/veto rights, revenue share. | Requires new economics handling (equity valuation, minority-stake/veto fields); new demo comparable. | `structureType: license \| equity \| compute_credits \| rev_share \| hybrid`; minority-stake/veto fields; one demo comparable. |
| G-8 | Scenario probabilities + confidence calibration | `ERC = Σ P×impact` is deducted, then GPV×CF multiplies again → risk charged twice. No P(down/base/up), so CAV is not a true expected value. | Changing the CAV semantics would break the seeded reconciliation and every downstream screen; must be designed, not patched. | Add P(up/base/down) (e.g. 25/50/25); compute probability-weighted EV; flag when CF×GPV diverges from EV; log CF calibration. |
| G-9 | Counterparty ZOPA/BATNA + portfolio-relative walk-away | Walk-away is set only against the deal's own CAV, not the partner's reservation, competitive alternatives, or the pipeline's marginal-return bar. | Needs new negotiation fields + a portfolio-context input; changes the negotiation brief UI. | Partner-alternatives fields; estimated ZOPA range visualized; walk-away = max(deal CAV, pipeline marginal bar). |
| G-10 | Option / renewal value priced as an option | Renewal is a probability assumption; pilots' information value and the renewal option's strike/volatility aren't priced; SOV not decomposed. | Requires real-options machinery; would change scenario outputs. | Price renewal as a call option; value pilot information value; decompose SOV into expand/abandon/wait. |
| G-12 | Partner dependency / single-point-of-failure score | Concentration cost is deal-level; no per-partner dependency score (revenue share, key-person, portability, data escrow, SLA reliance). | New scoring dimension; low urgency for a single-case demo. | `dependencyScore` on partner; surfaced on risk register + dashboard concentration panel. |
| G-13 | Non-compete / poaching / non-solicit terms | Common in data/product partnerships; absent from intake and data model. | Field additions with no model change; low urgency. | Add fields to ProposalTerms intake. |
| G-14 | Warranties / indemnities / liability caps / usage-audit clauses | Termination rights captured; warranty/indemnity/audit missing. | Field additions; low urgency. | Add fields to ProposalTerms + diligence checklist. |
| G-16 | Value-distribution / split modeling | Creation (GPV) and appropriation (ours) modeled; no "if it creates $35M, what split does each structure imply?" view. | Requires a new computation + negotiation-brief section; pairs with G-9. | Split table per scenario × structure driven by the give/get matrix + partner value mirror. |

## Reversal conditions (if any of these become required before v1.0 ships)

- If a reviewer of the demo explicitly asks for equity/compute-credit deal shapes → promote G-7.
- If the audience (frontier-AI partnerships) treats the absence of a regulatory screen as a
  credibility gap → this is G-3, which is **already included in v1.0** (MVP, not backlog).
- If the seeded reconciliation must change for any reason → G-8 becomes blocking (it defines
  CAV semantics).
- Otherwise, ship v1.0 with the bounded set and fold these into v1.1.
