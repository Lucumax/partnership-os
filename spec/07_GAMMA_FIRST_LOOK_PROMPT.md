# 07. Gamma prompt for a first-look deck

Paste the text below into Gamma.

---

Create a 9-slide executive strategy presentation titled:

**Partnership Value OS**

Subtitle:

**Defensible partnership decisions when comparables are sparse**

Audience:

A senior Product Partnerships, Strategy & Operations, Finance, Product, Research, and Legal audience at a frontier AI company.

Purpose:

Show a working approach to valuing, negotiating, and operationalizing novel data and product partnerships. The presentation is a proof of work, not a sales pitch. It should feel like an internal decision memo or investment-committee presentation.

Visual style:

- restrained, analytical, and executive;
- off-white or very light neutral background;
- dark charcoal text;
- one muted accent color;
- no gradients;
- no stock photography;
- no decorative AI imagery;
- no chatbot visuals;
- clean financial tables and simple diagrams;
- dense enough to show real thinking, but readable;
- strong footnote and source areas;
- use labels such as “Synthetic case” wherever relevant.

Do not invent factual claims about Anthropic or any real partnership. All case economics must be labeled synthetic.

## Slide 1: The decision problem

Title: **Valuing product partnerships when comparables are sparse**

Core message:

Novel AI partnerships combine direct economics, product capability, distribution, data uniqueness, strategic option value, implementation burden, exclusivity, and risk. A single market multiple is rarely enough.

Include a concise fictional case:

Atlas Knowledge Systems proposes a three-year data-license, API, product-integration, and enterprise-distribution partnership with limited exclusivity.

Add a bottom-line question:

**What is the partnership worth, how should it be structured, and what should the deal lead carry into negotiation?**

## Slide 2: Valuation architecture

Title: **A transparent value stack, not a black-box score**

Show a clean equation or stacked framework:

Direct financial value
+ Usage and customer value
+ Product capability value
+ Distribution value
+ Strategic option value
+ Learning value
- Cash consideration
- Implementation cost
- Exclusivity and opportunity cost
- Expected risk cost
- Concentration and lock-in cost
= Gross partnership value

Then:

Gross partnership value × confidence factor = confidence-adjusted partnership value

Add a side panel showing the five confidence dimensions:

- evidence quality;
- assumption stability;
- comparable quality;
- implementation certainty;
- partner execution confidence.

## Slide 3: Synthetic proposal

Title: **Atlas proposal: attractive upside, expensive commitment**

Show a two-column deal summary.

Synthetic terms:

- 36-month term;
- $4.0M upfront payment;
- $6.0M annual license;
- $3.0M annual minimum usage;
- $1.5M implementation support;
- limited category exclusivity;
- joint enterprise distribution;
- renewal option after year three.

Show four unresolved questions:

- uniqueness and replaceability of the data;
- evidence supporting enterprise distribution;
- implementation resources;
- opportunity cost of exclusivity.

## Slide 4: Scenario valuation

Title: **The base case does not clear the proposed economics**

Use a clean table:

Downside:
- gross value $14.0M;
- confidence factor 0.55;
- confidence-adjusted value $7.7M.

Base:
- gross value $35.0M;
- confidence factor 0.72;
- confidence-adjusted value $25.2M.

Upside:
- gross value $62.0M;
- confidence factor 0.78;
- confidence-adjusted value $48.4M.

Total proposed economic cost: $31.0M.

Highlight:

- downside gap: -$23.3M;
- base gap: -$5.8M;
- upside gap: +$17.4M.

Add a simple waterfall for the base case showing positive value components and deductions.

## Slide 5: Comparable-transaction discipline

Title: **Normalize imperfect comparables instead of pretending they match**

Show a five-row synthetic comparable table:

- Northstar Data License;
- Meridian API Integration;
- Harbor Enterprise Channel;
- Keystone Strategic Alliance;
- Pioneer Hybrid Agreement.

Columns:

- archetype;
- disclosed economics;
- term;
- exclusivity;
- distribution commitment;
- integration burden;
- source quality;
- comparability score;
- adjustment note.

Add a callout:

**Comparables inform the range; they do not replace first-principles valuation.**

## Slide 6: Negotiation recommendation

Title: **Restructure into a staged pilot before a three-year commitment**

Show:

- opening position;
- target range;
- reservation value;
- walk-away point;
- preferred structure.

Recommended structure:

- 9–12 month pilot;
- lower upfront payment;
- usage-based component;
- exclusivity limited by segment and milestone;
- termination rights tied to quality and implementation;
- renewal option triggered by usage and product metrics.

Include a give/get matrix with three examples.

## Slide 7: Operating system

Title: **Turn one-off deal analysis into a reusable partnership system**

Show a horizontal lifecycle:

Inbound proposal
→ structured term extraction
→ diligence questions
→ comparable retrieval
→ assumption register
→ valuation scenarios
→ red-team challenge
→ negotiation brief
→ approvals
→ contracting
→ realized-value tracking
→ benchmark-library update

Mark where Claude assists and where human approval is mandatory.

Use two labels:

- `Claude assists`
- `Human decision gate`

## Slide 8: Reliability and traceability

Title: **AI accelerates the work; it does not own the judgment**

Show six controls:

- every assumption visible;
- every benchmark linked to evidence;
- synthetic facts separated from public facts;
- confidence levels explicit;
- AI drafts labeled;
- final recommendations human-approved and auditable.

Add a small decision-history timeline showing an assumption change and resulting recommendation change.

## Slide 9: What the prototype demonstrates

Title: **A working model of the role, not a speculative essay**

Show four capabilities:

1. Valuation frameworks and financial modeling.
2. Deal support and negotiation strategy.
3. Cross-functional operating systems.
4. Claude-enabled analysis with human governance.

Close with:

**The app converts ambiguous partnership proposals into transparent assumptions, defensible valuation ranges, actionable negotiation positions, and reusable organizational learning.**

Footer note:

All companies and economics in this case are fictional and used solely to demonstrate methodology.
